# homebrew-tap

Homebrew tap for outbit packages.

## Usage

```shell
$ brew install outbit/tap/tempyenv
```

Or tap it first, then install:

```shell
$ brew tap outbit/tap
$ brew install tempyenv
```

## Formulae

| Formula | Description |
| --- | --- |
| [`tempyenv`](Formula/tempyenv.rb) | An easy and quick way to create a temporary Python virtual environment. |
